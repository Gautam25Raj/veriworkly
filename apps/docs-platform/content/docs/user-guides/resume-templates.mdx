# Resume Templates

VeriWorkly separates professional data (your Master Profile and documents) from visual presentation
(the template). Switching templates never modifies or loses data, so you can cycle through the whole
library to compare layouts.

---

## Resume templates

Both are free. There is no template lock on resumes or cover letters.

## Dual-engine rendering

Each template is implemented twice against the same data:

1. **Web engine (`web.tsx`)** — React and Tailwind CSS 4, powering the live paged preview.
2. **PDF engine (`pdf.tsx`)** — `@react-pdf/renderer` primitives, producing the exported PDF with
   embedded fonts and real vector text.

Both read the same `ResumeCustomization` object, which is what keeps the preview and the export
visually aligned. See [Export Pipeline](/docs/architecture/pdf-generation).

## Template metadata

Each template exports a `meta.ts` describing itself to the picker:

```typescript
export const precisionAtsMeta = {
  id: "precision-ats",
  name: "Precision ATS",
  documentType: "RESUME",
  description: "A dense, recruiter-friendly layout …",
  accentColor: "#10b981",
  previewImage: "/templates/resume/precision-ats.png",
  tags: ["One column", "ATS-friendly", "Compact", "Simple"],
} satisfies TemplateMeta;
```

## Customisation

Every template honours the same customisation object:

- **Colours** — accent, body text, muted text, page background, section background, borders, and
  section headings, each independently set.
- **Typography** — font family (which drives PDF font embedding) plus body and heading line heights.
- **Spacing** — section spacing and page padding.
- **Structure** — per-section visibility and ordering, and for two-column templates, a left/right
  column assignment per section.

See [Resume Schema](/docs/architecture/resume-schema#customization) for the full field list.

## Adding a template

1. Create `apps/studio/templates/resume/{your-template}/` containing `meta.ts`, `web.tsx`, and
   `pdf.tsx`.
2. Register the metadata and web renderer in `apps/studio/templates/index.ts`.
3. Register the PDF component in `apps/studio/templates/resume/pdf/index.ts`.
4. Verify against `/pdf-debug/resume/{your-template}`, the internal PDF rendering debugger.

New templates are welcome contributions — see the
[Contributing Guide](/docs/contributing/index).
