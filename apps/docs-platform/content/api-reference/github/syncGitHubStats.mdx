---
title: (Admin) Sync GitHub
description: >
  Manually triggers a GitHub sync. **Administrators only** — the caller's
  session email must

  match the configured `ADMIN_EMAIL`; an API key cannot reach this route.


  Incremental by default: only issues updated since the last sync are refetched.
  The run is

  guarded by a 10-minute Redis lock, so a concurrent attempt fails with `409`
  rather than

  double-syncing.


  A sync can take minutes, so it runs in the background: the response is `202`
  as soon as

  the lock is taken. `GET /github/stats` shows the new `syncedAt` once it has
  finished; a

  failed run leaves the previous data in place.
